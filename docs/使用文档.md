# 使用文档

> 「健身日程」是一款纯本地、离线的健身计划与训练记录 App。不需要注册账号，不联网，所有数据只存在你自己的手机上。

## 1. 功能一览

- **今日**：看今天该练什么，一键开始/继续训练。
- **计划**：编排训练计划（练哪些动作、几组几次、组间休息多久），并把计划排到星期几。
- **统计**：用图表回看容量趋势、训练频率、肌群分布、动作重量进步。
- **桌面组件**：在桌面直接看到「今天练什么、练到哪了」。

首次启动会自动导入 60 个内置动作（覆盖胸、背、腿、臀、肩、手臂、腹），按肌群和器械分类，可以直接使用。

## 2. 安装

- **自己构建**：见《部署文档》，产出 `app-debug.apk` 后安装。
- **命令行安装**：`adb install -r app-debug.apk`。
- 首次打开会看到「今日」页；此时还没有计划，会提示去「计划」页创建一个。

## 3. 界面总览

底部（平板为侧边）有四个入口：

| 入口 | 作用 |
|---|---|
| 今日 | 当天的训练安排与训练入口 |
| 计划 | 管理训练计划、动作编排与日程 |
| 统计 | 训练数据的图表与历史 |
| 我的 | 暂为占位页，后续放动作库/体重/设置 |

## 4. 今日

- 顶部显示今天的日期与星期。
- 如果今天排了计划，会以卡片列出每个计划的名称、动作数量，并提供「开始训练」按钮。
- 卡片上标注了该计划的动作编排（动作名 + 目标组数 × 次数）。
- 如果今天没有安排，显示「今天休息」空态，并提示去「计划」页排日程。
- 如果上次训练没练完就退出了，今天的页面顶部会出现「未完成的训练」卡片，按钮变成「继续训练」，可接着上次的进度练。
- 从训练记录页返回后会自动刷新当天状态。

## 5. 计划

### 5.1 新建 / 重命名 / 删除计划

- 右下角 **+** 新建计划，填写「计划名称」和可选「备注」。
- 计划卡片右侧的铅笔图标可重命名/改备注。
- 垃圾桶图标可删除计划。删除会**级联删除**该计划的动作编排和日程安排；已经产生过的训练历史会保留（只是不再关联到该计划）。

### 5.2 编辑动作编排

点开一个计划进入编辑页：

- 右下角 **+** 打开「选择动作」页，可按**肌群**（胸/背/腿/臀/肩/手臂/腹）和**器械**（杠铃/哑铃/器械/绳索/自重）筛选，点一个动作即加入计划并自动返回。
- 每个动作卡片显示目标：`N 组 × M 次` 与 `休息 K 秒`。
- 点「编辑目标」可修改组数、次数、组间休息秒数。
- 长按拖动排序图标可调整动作顺序，顺序会保存。
- 每个动作可单独「移除」。

### 5.3 日程

计划页右上角日历图标进入「训练日程」：

- 按星期一到星期日分成七张卡片，显示每天已排的计划。
- 点某一天的「添加计划」，从下拉里选一个计划排进这一天（已经排过的计划不会再出现）。
- 每个已排计划右侧的 ✕ 可移除排期。
- 目前只支持**按星期循环**的排期；「某一天一次性安排」的能力尚未开放。

## 6. 训练记录

从「今日」页的「开始训练 / 继续训练」进入。

- **逐组录入**：每个动作按目标组数展开若干组，填写重量（kg）和次数；勾选「完成」即记录这一组。已勾选的组会立刻保存，中途退出甚至杀进程都不会丢。
- **计时类动作**（如平板支撑、悬垂举腿）：输入秒数进行记录。
- **组间休息**：勾选完成一组后自动开始倒计时，倒计时结束会震动提醒；可随时「跳过休息」。休息时长取该动作设置里的值。
- **加组 / 减组**：可临时增减某个动作的组数。
- **跳过动作**：某个动作今天不想练，可标记「跳过」，之后也能「恢复」。
- **计划外动作**：训练中可「添加计划外动作」，临时加练不在计划里的动作。
- **备注**：可给本次训练写一条备注。
- **结束训练**：完成后进入训练完成汇总，显示完成组数、总容量（kg）和用时。
- **暂时退出 / 放弃**：
  - 「暂时退出」保留已完成的进度，之后可从今日页「继续训练」。
  - 「放弃训练」会删除本次训练记录。

## 7. 统计

- 时间范围可切换「近 7 天 / 近 30 天」。
- 顶部概览：总容量、训练次数、完成组数。
- 四张图表：
  - **容量趋势**：每天的训练容量（重量 × 次数之和）。
  - **训练频率**：每天的完成组数。
  - **肌群容量分布**：各肌群在这段时间里的容量占比。
  - **重量进步**：主要动作的最大重量随时间的变化，可在图表上切换动作。
- 底部是「训练历史」列表，点任意一条可以打开那次训练的详情。

## 8. 桌面组件

- 在桌面长按空白处 → 小组件，找到「今日训练」并添加。
- 组件会显示今天日期和状态：
  - 今天休息（没有排期）
  - 还没开始（今天有计划但还没练）
  - 训练中 · 已完成 N 组
  - 今日已完成 N 组 · X kg
- 组件会列出今天要练的计划（最多显示几个，更多会折叠成一行）。
- 点击组件可直接打开 App。

## 9. 「我的」（尚未实现）

「我的」Tab 目前是占位页，规划中的功能包括：动作库管理（按肌群/器械筛选、新增自定义动作）、体重记录、设置（主题配色、默认组间休息等）、关于页。这些暂未开放。

## 10. 数据与常见问题

**数据存在哪？**
全部保存在手机应用私有目录的 `fitplan.db` 中，不联网、不上传。应用参与系统的自动备份（`allowBackup=true`），换机时可能随系统备份一起恢复。

**动作库能改吗？**
内置 60 个动作是种子数据，升级种子版本只会**新增**动作，不会覆盖或删除你已有的记录。自定义动作的新增功能尚未开放。

**会提醒我训练吗？**
当前版本**没有**提醒/闹钟通知功能。只有训练页的组间休息倒计时会在到点时震动。

**删除了计划，我的训练记录会丢吗？**
不会。训练历史会保留，只是不再关联到被删除的计划。

**卸载重装会怎样？**
会清空本地数据，并重新导入 60 个内置动作。

**为什么 debug 版和正式版数据不互通？**
两者的包名不同（debug 为 `com.fitplan.app.dev`），属于两个独立应用。
