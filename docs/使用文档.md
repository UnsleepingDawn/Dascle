# 使用文档

> 「Dascle」是一款纯本地、离线的健身计划与训练记录 App。不需要注册账号，所有数据只存在你自己的手机上。
> 唯一的联网行为是检查新版本（见 [9. 「我的」与设置](#9-我的与设置)），不会上传任何数据。

## 1. 功能一览

- **今日**：看今天该练什么，一键开始或继续训练。
- **计划**：训练日历 + 计划管理。在日历上把计划排到某一天，在计划里编排练哪些动作、几组几次、组间休息多久。
- **统计**：用图表回看肌群组数分布、动作重量进步。
- **我的**：个人信息、设置（训练提醒 + 检查更新）、关于。
- **桌面组件**：在桌面直接看到「今天练什么、练到哪了」。

首次启动会自动导入 67 个内置动作（覆盖胸、背、腿、臀、肩、手臂、腹），按肌群和器械分类，可以直接使用。

## 2. 安装

- **下载安装包**：到 [Releases 页面](https://github.com/UnsleepingDawn/Dascle/releases/latest) 下载最新的 `.apk`，在手机上点击安装。
- **自己构建**：见《部署文档》。
- 系统要求：Android 8.0（API 26）及以上。

首次安装需要在系统设置里允许「安装未知来源应用」。首次打开会看到「今日」页；此时还没有计划，会提示去「计划」页创建一个。

## 3. 界面总览

底部（平板为侧边栏）有四个入口：

| 入口 | 作用 |
|---|---|
| 今日 | 当天的训练安排与训练入口 |
| 计划 | 训练日历，以及计划与动作编排的管理 |
| 统计 | 训练数据的图表与历史 |
| 我的 | 设置（目前是训练提醒） |

### 3.1 打开 App 时的漏练提醒

如果你有一段时间没打开 App，这段日子里排了训练却没有任何训练记录，打开 App 会先弹窗问你这些没练的计划怎么处理。弹窗只告诉你**从哪天到哪天、一共多少天**安排了训练但没记录（最多往回看 60 天），不列具体是哪些日子。

弹窗分两步：

1. **健身了，没写上去**：只是别再问了，日历一动不动（要补记录可以自己去「计划」里回想）。点弹窗外或按返回键等同这个选择。
2. **没有健身**：再选怎么处理这些没练的计划：
   - **顺延**：把这些没练的计划挪到之后，日历上今天及以后的安排（含休息日）整体往后推，推的天数正好是「上次练完之后到昨天」这一段，练 / 休的节奏原样保留。
   - **跳过**：删掉这些没练的计划，今天按原来的安排继续。

处理过一次之后，同一天不会再问；下次打开只在「上次处理之后」的日期里继续检查。全新安装、还没有任何训练记录时不会弹这个窗。

## 4. 今日

- 顶部显示今天的日期与星期。
- 如果今天排了计划，会以卡片列出每个计划的名称、备注、动作数量，以及每个动作的目标（如 `3 组 × 10 次 · 20 kg`），底部是「开始训练」按钮。
- 一天只有一个训练计划：今天这次训练**结束之后**，计划卡片的「开始训练」会变灰，下面会多出一句鼓励语和一张「还想练？」卡片，点「再来！」可以接着往今天这次训练里加练计划外的动作。
- 如果今天这次训练**没有对应的计划卡片**（休息日点小人「临时加一个方案」练出来的那种），完成态会在鼓励语**上面**补一张总结卡片，列出方案名、动作数量，以及每个动作实际练了多少（如 `3 组 × 10 次 · 60 kg`），一眼能看出今天练了什么。
- 如果今天没有安排（被编排成休息日），整页换成休息页：居中的小人图标 + 「今天休息」+ 一句随机寄语。
  - 今天还没开练时，点一下小人图标可以逐级「升级」：「不想休息？」→「还想练？」→ 字号一路变大的「开练！」，
    最后给出两个出口：
    - **使用明天的方案**：把今天之后最近一次训练的安排挪到今天，之后的计划与休息日整体**提前**，
      练 / 休节奏原样保留。会先弹窗说明挪的是哪一天、之后提前几天，确定后直接进训练记录页开练。
      之后完全没有安排训练时该按钮置灰，只能用临时方案。
    - **临时加一个方案**：直接开一场空的训练（计划外），练什么自己在训练里加，排期一动不动。
  - 开始训练后，今天就不再是休息日（休息标记自动撤掉），今天这次训练在日历里叫**「临时方案」**：
    今日页直接变成训练卡片（「继续训练」或「未完成的训练」），日历上今天会显示练到的肌群。
    中途点「放弃训练」把它删掉，今天会还原成休息日。
  - 今天已经练过、或还有一次没练完的训练时，休息页保持静态，只给出「继续训练 / 还想练？」的入口。
- 如果上次训练没练完就退出了，对应计划的按钮会变成「继续训练」，可接着上次的进度练；如果那次训练不属于今天排的计划（比如计划外训练），会在列表顶部单独出现一张「未完成的训练」卡片。
- 从训练记录页返回后会自动刷新当天状态。

## 5. 计划

### 5.1 训练日历

打开「计划」Tab 直接就是训练日历，按整月显示。

- 每个格子显示日期；有训练的日子用主色高亮（今天及以后按排期或已经开练算，过去按实际训练算），
  今天另有一圈描边，已经过去的日子整体压淡一档。
- 训练日与休息日的日期底色是同一套蓝色（今天及以后是饱和的主色，过去是更浅的淡蓝），
  是不是休息日由格子里那行「休息」说明——今天及以后是深绿，过去是跟肌群标签一样的灰。
- 日期下方列出当天的肌群，最多 3 个，多出来的显示成「+N」。
- 今天及以后显示**排期计划里的**肌群；今天已经开练却没有排期时（休息日的「临时方案」）显示实际练到的肌群。
  **过去的日子只显示实际练到的**肌群，那天没练过就是空白（早些时候排了却没练的日子不会假装有记录）。
- 顶部可切「上个月 / 下个月」，右侧「本月」一键回到当月。
- 点某一天弹出当天明细（小屏是底部弹层，平板是侧边面板），今天及以后分两块：
  - **实际训练**：那天真正完成的训练，灰色条目显示训练名与完成组数（没有就不显示）。
  - **当天计划**：那天排了哪些计划，点计划名可直接进入它的动作编排页。
- **已经过去的日子不再显示「当天计划」**——过去没法再规划，明细里只有「实际训练」，
  那天没练过就显示一行「这一天没有进行训练」；若这天标过休息，仍会列出「休息」条目（右侧 ✕ 可取消）。
- 明细里的三个条目（休息 / 当天计划 / 实际训练）都是整行一个色条，右侧的编辑、删除按钮也含在色条里。

### 5.2 添加 / 移除排期

当天明细右下角有两个按钮：

- **添加计划**：从计划里选一个排到这一天（只影响这一天，适合临时调整）。
  一天只能有一个训练计划，所以这个按钮**只在既没有排期、也没有实际训练的空白天可用**，其余情况是灰的——
  想改这天练什么，就先移除已有的排期再加；这天已经练过了，就直接编辑「实际训练」里的那次训练。
  若这一天**已经过去**，加进去的计划会直接补记成一次**实际训练**：按计划目标把每个动作的每组都记为已完成，
  所以日历格子里照样显示练到的肌群、统计页也算一次训练；补记的训练可以在「实际训练」条目上点铅笔进入记录页改。
- **该天休息**：把这一天标成休息日。一天不是训练日就是休息日，所以标休息会顺带撤掉这一天原有的排期；
  反过来，给休息日添加计划也会把休息标记撤掉。已经是休息日时该按钮置灰。

已排计划右侧的 ✕ 可移除这一天的排期，「休息」条目右侧的 ✕ 可取消休息日；
已经补记过的计划不会再出现在这一天的选择列表里，避免同一天记出两次同样的训练。

### 5.3 计划管理

日历顶栏右侧有两个入口：**设置单日方案** 进入「设置单日方案」列表页，**编排多日循环** 进入多日循环编排页（见 5.5）。

一个方案都没建过时，页面正中会提示「还没有可以被编排的单日方案！新建一个，然后在里面添加你的动作！」。

- 底部整条 **新增单日方案** 新建方案：第一个框填「名称」，第二个框填可选「备注」。
  保存后会**直接进入新方案的动作编排页**（见 5.4），可以顺手把动作加进去。
- 卡片右侧有两枚浅色按钮：
  - **安排动作**：进入这个方案的动作编排页。
  - **编辑名称**：改名 / 改备注。
- 卡片不显示「暂无备注」——没写备注就只显示名称与动作数量，所有卡片高度一致。
- **长按卡片**，或者把卡片**向左滑**露出红色「删除」再点它，都会先弹确认框再删除。
  删除会**级联删除**该计划的动作编排与所有排期；已经练过的训练历史会保留（只是不再关联到该计划）。

### 5.4 动作编排

- 底部有两个蓝色按钮：**单独动作** 打开「选择动作」页，可按**肌群**（胸 / 背 / 腿 / 臀 / 肩 / 手臂 / 腹）和**器械**（杠铃 / 哑铃 / 器械 / 绳索 / 自重）筛选；点一个动作即加入计划并自动返回。**动作组** 则新建一个空的动作组——一组可互相替换的动作（比如三个推类动作里挑两个做），在组卡片里设「做其中 x 个」，再往里添加组内动作。
- 新加进计划的动作默认是 **3 组 × 10 次、休息 90 秒**；内置动作在种子里标了默认重量或默认时长的，会一起带进来。
- 每个动作卡片显示目标，形如 `3 组 × 10 次 · 20 kg · 休息 90 秒`。
- 点铅笔图标「编辑目标」：
  - 先选这个动作是**计数**还是**计时**（如平板支撑选计时）。
  - 计数：填组数、次数、**默认重量（kg，可选）**、组间休息秒数。
  - 计时：填组数、时长（秒）、组间休息秒数。
  - 默认重量 / 默认时长只是「预填值」，训练时会自动填进输入框，你仍可以现场改。
- 长按左侧的拖动图标可调整动作顺序，松手即保存。
- 每个动作可单独「移除」。

### 5.5 编排多日循环

顶栏 **编排多日循环** 打开编排页，用 Day 1 / Day 2 / Day 3… 的格子排出一套循环。

- 点空格子选「训练」（再挑一个计划）或「休息」；点已填的格子可以改选或「移除这一天」。
- 顶栏 **应用** 决定怎么铺：**循环次数**（1–52，默认 4 次）或 **截止到**（选定日期为止），从起始日期起一次最多铺 366 天。
- 编排只在内存里，退出页面即丢弃；想改某一天，用日历上的当天明细。

## 6. 训练记录

从「今日」页的「开始训练 / 继续训练 / 再来！」进入；从「统计」页的训练历史点进来，看到的是同一条记录的只读回看。

- **逐组录入**：每个动作按目标组数展开若干组，填写重量（kg）和次数；勾选「完成」即记录这一组。计划里设了默认重量 / 默认时长的话，输入框会预先填好。已勾选的组会立刻保存，中途退出甚至杀进程都不会丢。
- **计时类动作**（如平板支撑、悬垂举腿）：输入秒数进行记录。动作卡片上可在「计数 / 计时」之间临时切换，但已经勾过组的动作不能切。
- **组间休息**：勾选完成一组后自动开始倒计时，到点震动提醒；可随时「跳过休息」。休息时长取该动作在计划里设置的值。
- **加组 / 减组**：可临时增减某个动作的组数。
- **跳过动作**：某个动作今天不想练，可标记「跳过」，之后也能「恢复」。
- **计划外动作**：训练中可用右下角按钮临时加练计划里没有的动作，同样按肌群 / 器械筛选，默认 3 组 × 10 次、休息 90 秒；末尾的确认按钮是红色的「结束训练」。
- **编辑已经结束的训练**：从「计划」（或今日页的「还想练？」卡片点「再来！」）进入已结束的训练时，底部同样是「添加计划外动作」+ 红色「完成编辑」并排，可以补记当时漏掉的动作和组。
- **备注**：结束训练时可以给本次训练写一条备注。
- **结束训练**：点右上角「结束训练」，确认后进入完成汇总，显示完成组数和用时。
- **暂时退出 / 放弃**：返回键或左上角返回会先问一次。
  - 「暂时退出」保留已完成的进度，之后可从今日页「继续训练」。
  - 「放弃训练」会删除本次训练记录。

## 7. 统计

- 顶部可切换「近 7 天 / 近 30 天」。
- 概览（2×2）：训练天数（区间内练了几天）、训练次数、完成组数、平均每周训练天数（固定看近 4 周，不受区间切换影响）。
- 两张图表：
  - **肌群组数分布**：各肌群在这段时间里记下的组数。多部位动作按主部位计入，次部位按 50% 折算。
  - **重量进步**：主要动作的最大重量随时间的变化，可在图表上切换动作。
- 底部是「训练历史」列表，只列出区间内最近的 5 次训练，点任意一条打开那次训练的详情（只读）。

## 8. 桌面组件

- 在桌面长按空白处 → 小组件，找到「今日训练」并添加。
- 组件会显示今天日期和状态：
  - 今天休息（没有排期）
  - 还没开始（今天有计划但还没练）
  - 训练中 · 已完成 N 组
  - 今日已完成 N 组
- 组件会列出今天要练的计划（最多显示几个，更多会折叠成一行）。
- 点击组件可直接打开 App。

## 9. 「我的」与设置

「我的」Tab 里有三个入口：**个人信息**、**设置**、**关于**。

### 9.1 设置

**训练提醒**：

- **开启训练提醒**：打开后每天在设定的时间检查一次，如果当天排了计划并且还没练，就发一条通知告诉你今天要练什么。当天已经练过、或者没有排期时不会打扰。
- **提醒时间**：默认 19:00，可点进去用时间选择器修改。
- **权限**：需要通知权限（Android 13+）和「闹钟与提醒」权限（Android 12+）。没给权限时页面会给出说明和一键授权入口：
    - 不给通知权限 → 到点不会发通知。
    - 不给「闹钟与提醒」权限 → 提醒仍会来，但可能晚几分钟。

**版本更新**：

- **启动时自动检查更新**：默认打开。打开时每次启动 App 会向 GitHub 查一次最新版本，一天最多查一次；只有真的有新版本才会弹窗。
- **镜像地址**：直连 GitHub 不通时用这个前缀重试，默认填了一个公共镜像；留空表示只直连 GitHub。

### 9.2 检查新版本

App 会在这些时候去看有没有新版本：

- **启动时静默检查**（开关打开时，每天最多一次）。查到更新会弹窗，写着新版本号和更新说明，点「去下载」用浏览器打开下载页，点「稍后再说」关掉；同一个版本只会提示一次。
- **手动检查**：「我的 → 关于」里点「检查更新」，绕过一天的间隔限制，右侧会显示结果：已是最新版本 / 发现新版本 x.y.z（点一下直接去下载页）/ 检查失败的原因（没连上网络、GitHub 暂时没响应、请求太频繁、GitHub 上还没发布可用的版本）。

下载到 APK 后覆盖安装即可，训练数据不会丢。

> 不想让 App 联网，就在设置里把「启动时自动检查更新」关掉；关掉之后只有你主动去「关于」页点「检查更新」才会发请求。

### 9.3 关于

显示应用名、版本号，以及「检查更新」与 GitHub 仓库入口。

## 10. 数据与常见问题

**数据存在哪？**
全部保存在手机应用私有目录的 `fitplan.db` 中，不会上传。应用参与系统的自动备份（`allowBackup=true`），换机时可能随系统备份一起恢复。

**App 会联网吗？**
只在检查新版本时联网：向 `api.github.com` 发一个只读请求拿最新 Release 信息，请求里没有你的任何数据。设置里关掉「启动时自动检查更新」后，就只有你主动点「检查更新」才会请求。检查更新失败（断网、被墙、请求太频繁）不会影响其他功能。

**动作库能改吗？**
内置 67 个动作是种子数据，升级种子版本只会**新增**动作，不会覆盖或删除你已有的记录。自定义动作的新增功能尚未开放。

**删除了计划，我的训练记录会丢吗？**
不会。训练历史会保留，只是不再关联到被删除的计划。

**卸载重装会怎样？**
会清空本地数据，并重新导入 67 个内置动作。

**为什么 debug 版和正式版数据不互通？**
两者的包名不同（debug 为 `com.fitplan.app.dev`），属于两个独立应用。debug 版只是开发用的，自己用请装 Releases 里的正式版。

**打开 App 时弹窗问我「这段时间有训练没记录」是怎么回事？**
那段日子里你排了训练，但没有留下训练记录，App 想让你先确认怎么处理：顺延、跳过，或者「健身了，没写上去」（只关掉提醒，日历不动）。详见 [3.1](#31-打开-app-时的漏练提醒)。
